# Skin-Cancer-Classification

## Overview

This repository contains exploratory Jupyter notebooks for skin cancer classification. The notebooks document initial experiments with data preprocessing and class balancing techniques for skin lesion analysis.

## Contents

The repository contains 4 Jupyter notebooks:

1. **main.ipynb** - Main classification experiments
2. **preproces.ipynb** - Data preprocessing exploration  
3. **preproces_2.ipynb** - Additional preprocessing experiments
4. **smotee.ipynb** - SMOTE (Synthetic Minority Over-sampling Technique) for class balancing

## Current Status

This is an **exploratory/learning** repository containing early-stage experiments with skin cancer classification. The notebooks represent:
- Initial data exploration and preprocessing
- Experiments with class balancing techniques
- Learning and experimentation with medical image classification
- Documentation of the exploration process

## Technical Details

- **Format**: Jupyter Notebooks (.ipynb)
- **Language**: Python
- **Focus**: Exploratory analysis and learning

## Usage

To view the notebooks:

```bash
git clone https://github.com/Hyder605/Skin-Cancer-Classification.git
cd Skin-Cancer-Classification
```
